# 首页待机循环动画 · Seedance

首帧与尾帧都使用 `public/art/originals/screen/summon-first-frame.png`，不使用含 UI 按钮或标题的页面截图。建议 8 秒，9:16 竖屏；与输入图保持相同构图。下面是创作约束，不保证模型能一次生成完全无缝的循环。

## 正向 prompt

以提供的同一张图片作为首帧和尾帧，生成一段 8 秒、9:16 竖屏、可无缝循环的萌物扭蛋小屋待机动画。保持原图温暖梦幻的高品质 3D 毛绒玩具风格、粉色与奶油色调、材质、光照、构图及全部角色身份。固定机位，扭蛋机、城堡、桥梁、礼盒的位置和形状始终不变，顶部天空区域保持干净，供网页叠加标题。

画面只发生轻微、柔软、慢节奏的局部运动：左下角抱草莓的白色毛绒兔轻轻呼吸，耳尖微微摆动；右下角薄荷绿色萌物缓慢眨眼一次，头顶两片嫩叶轻轻摇摆。玻璃球内的小伙伴只偶尔眨眼，身体与所在胶囊不位移、不互相穿透。远处桥边垂挂的金色小星星像微风中的吊饰一样小幅来回摇动。前景云朵边缘缓缓起伏，远景云层极轻地往返漂动。玻璃罩上有一条柔和反光缓慢掠过，少量细小星点低亮度呼吸闪烁，不遮挡角色。

所有动作组成一个完整且连续的循环：前半段缓慢偏离初始姿态，后半段自然回到初始姿态；闭眼动作在中段完成，末尾恢复原图眼睛状态。最后一帧与第一帧的角色姿态、耳朵与叶片角度、星星位置、云层形状、反射和亮度一致，运动速度也平滑衔接。整个画面始终处于等待玩家点击的安静状态，不启动抽卡，不发生剧情。

## 避免

镜头推进、缩放、摇镜、转场、切镜、景深抽动；扭蛋机摇晃、旋钮转动、出球、胶囊翻滚；大幅摇头、夸张蹦跳、角色变形、多余耳朵或肢体、眼睛错位、胶囊穿模；新增角色、文字、logo、水印；强烈光闪、粒子爆炸、明暗突变；用淡入淡出、黑场或倒放制造循环。

生成后先连续播放三轮，检查首尾是否跳帧、呼吸节奏是否突然停顿。若接缝明显，优先降低动作幅度与粒子数量。
