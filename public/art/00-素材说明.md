# 绒绒星球图片素材

这个目录按**用途**分开。网页使用 WebP/JPG；PNG 原图保存在 `originals/`，未采用的方案保存在 `drafts/`。

| 文件夹 | 内容 |
| --- | --- |
| `characters/ssr/` | 3 张 SSR 的双形态角色图：奶兔、星眠小猫、月桂小驼，各 2 张 |
| `characters/sr/` | 3 张独立 SR 角色图 |
| `characters/r/` | 6 张独立 R 角色图 |
| `characters/atlas/` | 早期 10 张 SR/R 角色共用的拼图 `friends.webp` |
| `card-parts/` | 正式卡框、卡背、收纳口袋 |
| `screen/` | 页面场景、按钮、Logo、Loading 和视频封面 |
| `originals/` | 对应的 PNG 原图；不要当成另一套卡片 |
| `drafts/` | 未接入正式卡池的角色、Logo、边框和口袋提案 |

## 22 张卡分别在哪里

**SSR（3 张）**：草莓奶兔 `bunny-a-repaired.webp` / `bunny-b-repaired.webp`；星眠小猫 `cat-a.webp` / `cat-b.webp`；月桂小驼 `alpaca.jpg` / `alpaca-alt.jpg`。均在 `characters/ssr/`。

**SR（7 张）**：枫糖小熊猫 `red-panda.jpg`、珍珠六角龙 `axolotl.jpg`、抱心小刺猬 `hedgehog.jpg` 在 `characters/sr/`；晚安企鹅、云朵狗狗、薄荷团子、软糖小龙在 `characters/atlas/friends.webp` 的上排，从左到右第 1～4 格。

**R（12 张）**：星帽小鸮 `owl.jpg`、四叶小鹿 `fawn.jpg`、雨衣小鸭 `duck.jpg`、莓莓小龟 `turtle.jpg`、月芽绵羊 `lamb.jpg`、贝壳小水獭 `otter.jpg` 在 `characters/r/`；蛋壳啾啾在拼图上排第 5 格，橘子水豚、桃桃小狐、瓜子团团、竹叶滚滚、泡泡海豹在下排第 1～5 格。

目前网页会把角色图、卡框、名字等合成为 800×1200 的完整卡面；这里保存的是组成卡片的图片素材，没有逐张预先导出的 22 张完整卡面。
